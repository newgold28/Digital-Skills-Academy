Digital Skills Training Academy Website

A responsive multi-page educational website built with HTML and CSS.

Project Overview

This project demonstrates the use of semantic HTML, hyperlinks, images, and modern CSS techniques to build a responsive educational website for a fictional Digital Skills Training Academy.

The website includes multiple pages, a navigation system, responsive layouts, and visually appealing styling using Flexbox, CSS Grid, shadows, borders, and background images.

Features

Multi-page structure

Includes Home, About, Courses, and Contact pages.

Internal and external links

Easy navigation between pages plus links to external resources.

Rich visual content

Uses multiple images with descriptive alt text.

Responsive design

Optimized for mobile devices, tablets, and desktops.

Modern CSS styling

Custom colors, rounded corners, shadows, Flexbox, and CSS Grid.

Project Structure
Pages
Home Page (index.html)

Features a hero banner, welcome message, navigation menu, featured courses section, and footer.

About Page (about.html)

Provides information about the academy, including mission and vision statements, along with supporting images.

Courses Page (courses.html)

Showcases at least five courses with images and brief descriptions for each course.

Contact Page (contact.html)

Contains contact information, a contact form, and social media links.
